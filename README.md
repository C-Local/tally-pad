\# Tally Pad



A mobile-first tally counter and tracker built with vanilla HTML, CSS, and JavaScript.



\## Features

\- Increment and decrement a running count

\- Save counts to a tracked list

\- Remove individual entries

\- Live total and average calculation

\- Slide-in animations on new entries

\- BEM CSS architecture

\- Event delegation for dynamic elements



\## Tech Stack

\- HTML5 (semantic elements, ARIA attributes)

\- CSS3 (custom properties, flexbox, keyframe animations)

\- Vanilla JavaScript (ES6+, array methods, DOM manipulation)



\## How to Run

Open `index.html` in any modern browser. No build tools or dependencies required.
